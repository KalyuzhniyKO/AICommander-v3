# Очистка процесса при отказе killpg

[English](PROCESS_CLEANUP.en.md)

CI macOS ARM64 выявил PermissionError при killpg в проверке большого Git diff. Исключение прерывало cleanup до wait(), затем следующий тест обнаруживал ResourceWarning о несобранном Popen.

Теперь OSError при уничтожении группы сохраняет признак ошибки, но не пропускает попытку остановки и wait() прямого дочернего процесса и закрытие его потоков. После очистки возвращается ExecutionError без сырого сообщения ОС. Неподтверждённая очистка дерева не считается успешным выполнением команды. Ограничение времени, output limits и обязательный macOS CI сохраняются.

Регрессия использует настоящие короткий и зависающий Python-процессы с синтетическим отказом killpg: оба должны быть собраны и вернуть ошибку containment. Локальный прогон нового исправления не выполнен: среда сессии отключилась. Приёмка требует CI, включая tests/test_process_cleanup.py, прежний test_evidence_size_limit_and_paths и test_resources, без ResourceWarning. Это не проверка Zorin или живых моделей.
